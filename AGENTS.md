## What This App Does

Dashboard thị trường tiếng Việt: tab Thế giới (BTC, vàng, dầu, FED, tin tốt/xấu, dự báo 5 mốc) và tab Trong nước (vàng SJC/9999/98/95, xăng dầu Petrolimex, lãi suất Agribank/Vietcombank/Sacombank). Chỉ cập nhật khi bấm Làm mới; bản gần nhất lưu ở localStorage. Backend dữ liệu: `bun run api` (scripts/market, cổng 3001), Vite proxy /api. Dự báo là mô hình động lượng + tin tức, lãi suất ngân hàng một phần là số liệu tham chiếu có ghi nguồn.

## Share links

- Starter apps already ship `getShareBase`, `buildShareLink` and `installShareSync` in `src/lib/share.ts`; import them instead of rewriting them.
- Keep shareable state in the URL path or query, not in the `#fragment`.
- Never put a secret (private key, claim secret, seed phrase, session token, API key) in the URL path or query, encoded or not: every in-app path and query is mirrored to the visitor's studio.arc.io address bar and browser history and reaches servers. A bearer claim secret goes only in the `#fragment` appended to the share link (`` `${await buildShareLink('/claim')}#${secret}` ``) and is read from `location.hash` on load. A link to the app's own share URL shown inside the app must be copy-only or open in a new tab with `target="_blank" rel="noopener noreferrer"`.
- Build every link a user copies or sends with `buildShareLink()` from `src/lib/share.ts`.
- Keep the `installShareSync()` call in `src/main.tsx` when editing it; it keeps the Studio address bar in step with in-app navigation.
- Navigate inside the app with relative links.
